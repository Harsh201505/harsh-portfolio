# Harsh Portfolio

A responsive, static portfolio website built with plain HTML, CSS, and JavaScript. No build step or package installation is required.

## Run locally

Open `index.html` in a browser, or use a local static-file server from this folder. For example, if Node.js is installed: `npx serve .`

## Included details

The site contains Harsh’s education, technical skills, internship experience, IT projects, contact email, LinkedIn link, and downloadable résumé. The résumé download is stored at `assets/harsh-resume.pdf`.

Before publishing, review the content and add a GitHub or project-demo link only if you have one you would like to share.

## Deploy

Upload the folder to Netlify, Vercel, GitHub Pages, or any static host. Set the publish directory to the project root—there is no build command. For GitHub Pages, push these files to a repository, then enable Pages in repository settings and deploy from the branch containing `index.html`.
